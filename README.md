# Data Science Portfolio

Personal data science portfolio showcasing projects in Python, SQL, and Power BI.

To verify completion of my DataCamp coursework, please visit my [DataCamp portfolio page](https://www.datacamp.com/portfolio/jdcf50).


## Projects

### [AMRO Analysis](./amro-analysis/)
Fermi surface symmetry analysis via angle-resolved magnetoresistance oscillations — a Python package for analyzing quantum electronic properties of materials.

### [Wildfire Risk Prediction](./wildfire-risk-prediction/)
Predicts wildfire risk for US properties using satellite fire detections, Census demographics, and ML models (XGBoost/RandomForest).

### [Recipe Site Traffic](./recipe-site-traffic/)
Machine learning case study involving a food recipe website seeking to increase traffic by identifying what kinds of recipes to display on their front page.

### [Predicting House Sale Prices](./house-sale-price-prediction/)
Machine learning case study predicting the sale price of houses for a real estate company seeking to reduce time to sale.

### [Manufacturing Process Control](./manufacturing-process-control/)
Statistical process control analysis using SQL window functions to monitor manufacturing quality and identify out-of-control measurements.

### [NGO Impact Analysis](./ngo-impact-analysis/)
Analysis of donation patterns and assignment impact for an NGO using PostgreSQL CTEs and aggregations.

### [Customer Churn Dashboard](./customer-churn-dashboard/)
Power BI case study analyzing churn rates for a telecom company to identify subscription cancellation patterns.

### [HR Analytics Dashboard](./hr-analytics-dashboard/)
Power BI case study analyzing human resources data for a software company, focusing on employee demographics, performance, and attrition.

### [Inventory Analysis Dashboard](./inventory-analysis-dashboard/)
Power BI case study analyzing logistics inventory, identifying risks and providing insights for provider retention.
